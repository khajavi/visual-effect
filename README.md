# Visual ZIO Effect

Interactive visualizations for [ZIO](https://zio.dev) programs. This project is derived from
its sister project, Kit Langton's [Visual Effect](https://github.com/kitlangton/visual-effect)
([live site](https://effect.kitlangton.com)), which visualizes the TypeScript
[Effect](https://github.com/Effect-TS/effect) library. Visual ZIO Effect ports the same
visualization engine and examples to demonstrate ZIO's (Scala) API and semantics instead.

## What is this?

An interactive Next.js app that visualizes how ZIO operations execute over time. Watch effects run, compose, race, and handle errors with animated nodes and synchronized sound feedback.

## Local Development

```bash
bun install
bun dev
```
